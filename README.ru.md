# Claude Control Bar

[English](README.md) | **Русский**

https://github.com/user-attachments/assets/39381f85-c8ce-4d32-8baa-dce67d39ee7e

Приложение для строки меню macOS, спутник **Claude Code**. Показывает, чем Claude занят, и даёт управлять сессиями, MCP-серверами и лимитами прямо из меню.

- **Сессии.** Анимированная иконка, пока Claude работает, жёлтая точка, когда он ждёт вашего разрешения, таймер хода и процент занятого контекста у каждой сессии. Клик по сессии поднимает терминал или редактор, где она запущена.
- **MCP.** У каждого сервера и каждого инструмента свой выключатель. Выключенный инструмент пропадает из контекста Claude при следующем старте сессии.
- **Лимиты.** Полоски 5-часового и 7-дневного лимитов прямо в строке меню, время сброса видно в самом меню.

## Установка

### Плагином Claude Code (рекомендуется)

```bash
/plugin marketplace add InfinityScripter/claude-control-bar
```

```bash
/plugin install claude-control-bar
```

Приложение собирается из исходников на вашем Mac при следующем старте сессии, для этого нужны Xcode Command Line Tools (`xcode-select --install`). Обновляется вместе с плагином.

### DMG

1. Скачайте `claude-control-bar.dmg` из [последнего релиза](../../releases/latest).
2. Перетащите **Claude Control Bar** в «Программы».
3. Запустите один раз, чтобы установились хуки. Без активной сессии Claude оно может тут же закрыться — это нормально: хуки уже на месте.

> [!IMPORTANT]
> DMG не нотаризован, поэтому macOS заблокирует первый запуск. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**. Или снимите карантин командой
> `xattr -dr com.apple.quarantine "/Applications/Claude Control Bar.app"`.

Ставьте что-то одно. Если установлены оба канала, каждый хук срабатывает дважды. Приложение умеет разруливать этот конфликт в пользу плагина, но держать оба всё равно незачем.

## Первый запуск

У приложения нет окна и иконки в Доке — оно живёт в **строке меню**, в правом верхнем углу экрана, рядом с часами. Открывать его самому не нужно: оно запускается вместе с первой сессией Claude Code и закрывается, когда сессий не остаётся.

После установки:

1. **Запустите новую сессию Claude Code** — `claude` в терминале или Code-сессию в desktop-приложении. Сессии, открытые до установки, появятся только после своего следующего промпта или вызова инструмента.
2. **Канал плагина: дождитесь первой сборки.** На первом старте сессии приложение компилируется из исходников, это занимает от минуты до трёх; иконка появится, когда сборка закончится. Если она так и не появилась — загляните в `~/.claude/control-bar/problems.log`.
3. **Найдите краба в строке меню.** Без работающих сессий он спит; пока Claude работает — ходит, а жёлтая точка значит, что сессия ждёт вашего разрешения. Кликните по иконке — сессии, выключатели MCP, лимиты и раздел Options живут в этом меню.

Иконки нет?

- Приложение из DMG, открытое руками, **сразу закрывается, если нет активной сессии** — это задуманное поведение, а не краш. Запустите его один раз, чтобы установились хуки, затем запустите сессию.
- Самая частая причина — забитая строка меню: macOS прячет не поместившиеся элементы за шеврон `›`, и со стороны это неотличимо от «приложение не запустилось». Уберите пару иконок из строки меню (перетаскивание с зажатым Cmd), чтобы освободить место.
- `pgrep -x ClaudeControlBar` в терминале: число — приложение работает и спрятана только иконка; пустой вывод — оно не запущено: запустите сессию или смотрите [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Как пользоваться

Сессии, лимиты, выключатели MCP и раздел Options живут в иконке в строке меню; запускается и закрывается приложение само, как описано выше.

### Маскот-краб

**Crab Walking** — анимация по умолчанию при новой установке. Маскот меняется в зависимости от числа сессий Claude Code, которые работают параллельно прямо сейчас. Считаются только сессии, где Claude думает или выполняет инструмент; просто открытые и бездействующие сессии не влияют.

| Работающих сессий | Что делает краб |
| ---: | --- |
| 0 | Спит |
| 1 | Отдыхает с сигарой |
| 2–3 | Ходит — спокойно при двух сессиях, в полный темп при трёх |
| 4–5 | Краснеет, качается и потеет |
| 6+ | У него загорается голова |

В этих превью используются те же runtime-кадры и тайминг, что и в приложении:

| 0 · Сон | 1 · Сигара | 2–3 · Ходьба |
| :---: | :---: | :---: |
| ![Анимация спящего краба](assets/crab-moods/sleeping.gif) | ![Анимация краба с сигарой](assets/crab-moods/cigar.gif) | ![Анимация идущего краба](assets/crab-moods/walking.gif) |
| 4–5 · Перегрев | 6+ · В огне | Нужно разрешение |
| ![Анимация перегревшегося краба](assets/crab-moods/overheated.gif) | ![Анимация краба в огне](assets/crab-moods/on-fire.gif) | ![Анимация краба в ожидании разрешения](assets/crab-moods/permission.gif) |

Когда сессии нужно разрешение, краб переключается на отдельную сцену ожидания: поднимает табличку со знаком вопроса, затем смотрит в экран. Рядом остаётся жёлтый предупреждающий кружок, а в строке состояния появляется короткая надпись `Needs you`. После ответа краб возвращается к состоянию для текущего числа работающих сессий.

Спрайт освещён сверху слева — светлая кромка сверху, тёмная снизу, — поэтому на размере строки меню он читается как объём, а не как наклейка; в режиме System это оттенённый монохромный силуэт. Внутри каждой полосы темп следует точному числу сессий: потеющий краб дышит чаще с пятой сессией, огонь мерцает быстрее с каждой следующей.

Выключатели серверов и инструментов действуют на новые сессии: Claude Code собирает список инструментов на старте, уже открытые сессии работают со старым набором.

### Options

Всё, что лежит в разделе **Options** меню (меню приложения на английском):

- **Timer in menu bar** — время текущего хода рядом с иконкой. В строках сессий таймер есть всегда.
- **Thinking words** — вместо «Thinking…» одно из слов-заставок самого Claude Code («Manifesting…»).
- **Limits via Anthropic API** — опрос, из которого берутся полоски 5-часового и 7-дневного лимитов; выключено — запроса нет вовсе (см. [PRIVACY.md](PRIVACY.md)).
- **Animation** — Crab Walking (по умолчанию), Claude Spark или Claude Code, спиннер из терминальных глифов.
- **Color** — Orange или System: адаптивная чёрно-белая иконка.
- **Sounds** — два события. *When a turn finishes*: выключено (по умолчанию), каждый ход или только ходы длиннее 1, 5 или 15 минут. *When Claude needs you*: короткий системный звук macOS в момент, когда сессия начинает ждать вашего разрешения — по умолчанию Tink, на выбор Purr, Ping, Glass, Hero, Submarine; выбор пункта сразу его проигрывает. Звука нет, если терминал или приложение с этой сессией и так на переднем плане: запрос уже на экране, слышать о нём незачем.
- **Check MCP now** (⌘R) и **Open settings.json** — проверить MCP прямо сейчас; каждый выключатель сервера и инструмента пишется в `~/.claude/settings.json`.

Ещё приложение показывает уведомление macOS, когда MCP-сервер упал или вернулся. Если уведомления запрещены, в меню появляется строка *Notifications are off*, которая открывает нужный раздел Системных настроек.

### Слэш-команды

Плагин добавляет в Claude Code две команды:

- `/mcp-health` — карта MCP текстом: какие серверы ответили, сколько у каждого инструментов, что выключено, плюс окно контекста каждой открытой сессии и лимиты.
- `/limits-capture install|uninstall|status` — необязательный второй источник для полосок лимитов. Оборачивает вашу команду `statusLine`, и цифры обновляются из данных, которые Claude Code ей передаёт, — свежее, чем опрос API, пока активна сессия в терминале; `uninstall` возвращает прежнюю команду в точности.

Настройки раскладки, ключи `defaults write` и диагностические режимы перечислены в [TROUBLESHOOTING.md](TROUBLESHOOTING.md#knobs-and-diagnostics).

Цифры лимитов приложение берёт с той же ручки Anthropic, что и команда `/usage`. Для запроса используется OAuth-токен из Keychain, который туда положил сам Claude Code. Уходит он только на `api.anthropic.com`, а опрос можно выключить в Options. Полный список файлов, которые приложение пишет, и запросов, которые оно делает, лежит в [PRIVACY.md](PRIVACY.md).

## Требования

- macOS 12+
- [Claude Code](https://claude.com/claude-code) (CLI или Desktop-приложение)
- Node.js и системный `/usr/bin/python3`
- Xcode Command Line Tools нужны только плагину (он собирает приложение локально), для DMG не нужны

## Удаление

Если ставили плагином: `/plugin uninstall claude-control-bar`, потом перетащите `~/Applications/Claude Control Bar.app` в Корзину.

Если ставили из DMG:

```bash
node "/Applications/Claude Control Bar.app/Contents/Resources/uninstall.js"
```

Скрипт убирает хуки, дальше перетащите приложение в Корзину. Служебные файлы лежат в `~/.claude/control-bar/`.
